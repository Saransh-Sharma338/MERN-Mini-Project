# MERN Mini Projects

This repository contains front-end web development mini projects.

## Projects Included

1. **Student Registration Form** (Student_Registration_Form/)
   - Complete student registration portal for SRM Institute of Science and Technology.
   - Comprehensive form inputs: Personal details, profile image, course selections, skills checklist, address, and learning preferences.
   - Structured HTML tables for course details, class schedules, and student performance tracking.

2. **Website Layout** (Website_Layout/)
   - Multi-section layout built with modern CSS Grid.
   - Includes header, sidebar navigation, dynamic content sections, and footer.
